# WHUT 本地摘要复用设计

## 1. 目标

当当天摘要文件已经存在时，邮件发送流程优先直接复用本地 `output/summary_YYYYMMDD.md`，不再重复抓取网页和调用 DeepSeek。

## 2. 规则

- 仅在“当天文件存在”时复用。
- 文件路径按现有规则：`output/summary_YYYYMMDD.md`。
- 复用时仍继续发送邮件。
- 若当天文件不存在，继续走现有抓取、总结、写文件、发邮件流程。

## 3. 实现方案

- 在 `main.py` 增加“获取今日本地摘要文件路径”的辅助函数。
- 启动时先检查今日本地摘要文件是否存在。
- 若存在：
  - 读取文件内容作为邮件正文来源。
  - 构造邮件主题并直接发送。
  - 终端输出“使用本地摘要文件”的提示。
- 若不存在：保持原有完整流程。

## 4. 错误处理

- 本地文件存在但读取失败：打印错误并回退到在线抓取流程。
- 邮件发送失败：仍保留本地文件，不中断程序。

## 5. 测试策略

- 测试当天摘要路径生成。
- 测试当本地文件存在时，不调用抓取与总结逻辑。
- 测试本地文件内容会被用于邮件正文。
